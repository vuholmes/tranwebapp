# Trang hỗ trợ và chính sách quyền riêng tư

Gồm `index.html` (Support URL), `privacy.html` (Privacy Policy URL) và `style.css`.

1. Mở 2 file html, thay `[TÊN NHÀ PHÁT TRIỂN]` và `[EMAIL LIÊN HỆ]` bằng thông tin thật của bạn.
2. Đưa lên GitHub Pages (hoặc bất kỳ nơi nào công khai, không cần đăng nhập).
3. Support URL = địa chỉ trang `index.html`, Privacy Policy URL = địa chỉ trang `privacy.html`.
